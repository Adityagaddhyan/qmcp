# qmcp

A minimal MCP server written in TypeScript.

## Requirements

- Node.js 18+
- npm

## Install

```bash
npm install
```

## Run (development)

```bash
npm run dev
```

## Build

```bash
npm run build
```

Compiled output goes to `dist/`.

## Start (after build)

```bash
npm run start
```

## Type check

```bash
npm run typecheck
```

## Project structure

- `src/index.ts` - server entrypoint
- `tsconfig.json` - TypeScript config
- `package.json` - project metadata and dependencies

## Notes

This is a minimal starter and is still under active development.
